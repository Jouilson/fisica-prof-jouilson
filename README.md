# Portal de Física - Prof. Jouilson

Portal colaborativo para trabalhos em grupo de Física, com:

- seleção de turma e equipe
- títulos sugeridos
- editor de texto rico (Quill)
- checklist de subtítulos
- chat da equipe
- painel do professor
- envio de relatório por e-mail

## Como abrir localmente

Abra o arquivo `index.html` em um navegador.

## Como publicar no GitHub Pages

1. Acesse o repositório no GitHub.
2. Vá em `Settings` > `Pages`.
3. Em `Build and deployment`, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
4. Salve.
5. Aguarde a publicação.

O site ficará disponível em algo como:

https://jouilson.github.io/fisica-prof-jouilson/

Observação: depende do plano da sua conta e da visibilidade do repositório.
Se o repositório estiver privado, pode haver restrição de GitHub Pages conforme sua conta.
