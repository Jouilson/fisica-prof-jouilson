# Portal de Física - Prof. Jouilson (Versão Online)
App full-stack: equipes online, salvar na nuvem, chat em tempo real, IA de pesquisa, PDF real e envio de e-mail.

## Deploy no Render (igual ao app de Matemática)
1. Suba estes arquivos para um repositório GitHub (package.json, server.js, public/index.html).
2. Render → New → Web Service → conecte o repo.
3. Build Command: `npm install` | Start Command: `npm start` | Instance: Free.
4. O `index.html` deve estar dentro da pasta `public/` (na raiz do repo).

## E-mail do professor
Envio via FormSubmit (sem conta). 1ª vez: professor recebe e-mail de confirmação, clica em "Activate Form" uma vez.
